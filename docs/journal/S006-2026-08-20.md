### 20:10 - Một ca test chưa bao giờ chạy

Mục 3 cũ (tính điểm rủi ro) mở đầu bằng một bảng tám mốc biên
`0 / 14 / 15 / 39 / 40 / 69 / 70 / 100` kèm nhãn mong đợi - rồi `break` ngay sau
vòng đầu tiên:

```csharp
foreach (var (score, expected) in new[] { (0, "Thấp"), (14, "Thấp"), ... })
{
    var rs = RiskScoring.Compute(new List<RiskFinding>(), false, 0);
    Check(rs.Value == 0, "khong phat hien -> 0 diem");
    break;                      // <-- bảy mốc còn lại chưa từng chạy
}
```

Thân vòng lặp còn không dùng tới `score` lẫn `expected`. Tức bảy mốc kia là
**trang trí**, và biến `expected` chưa bao giờ được so với gì cả.

**Đã làm cho nó chạy thật.** `RiskScoring.Compute` cộng theo trọng số từng
nhóm (`genuineFailed` 40, Critical 15/cái trần 30, High 10/cái trần 30, Medium
5/cái trần 15, kiểm tra thủ công 2/cái trần 15), nên chạm đúng từng mốc được:

| Mốc | Cách chạm |
|---|---|
| 14 | 7 mục kiểm tra thủ công |
| 15 | 8 mục kiểm tra thủ công → `min(16, 15)` = trần |
| 39 | Medium×3 (15) + High×2 (20) + thủ công×2 (4) |
| 69 | genuineFailed (40) + Critical×1 (15) + Medium×2 (10) + thủ công×2 (4) |
| 100 | genuineFailed (40) + Critical×2 (30) + High×3 (30) |

`RiskScoringTests.Bien_cua_tung_nhan_diem` - `[Theory]` tám dòng, **cả tám
xanh**. Không phải sửa mã sản xuất; luật vốn đã đúng, chỉ là chưa ai kiểm.
